Getting started

Getting into Dereth

Four steps between here and standing on the shore. Most of it is one-time setup — after that, it's just launching Thwarg and picking Buadren AC from the list.

Check server status

  1. 1 Get your game files

    Buadren AC runs on ACE, so you'll need a working copy of the original Asheron's Call: Throne of Destiny client files before anything else will connect.

    ACE's how-to-play guide

  2. 2 Install Thwarg Launcher

    Thwarg Launcher is what actually connects your client to emulated AC servers, Buadren AC included. Grab the installer from the official site.

    Download from thwargle.com

  3. 3 Find Buadren AC in the server list

    Open Thwarg Launcher, go to Browse Servers, and look near the bottom of the list for Buadren AC. Selecting it connects you to our live server.

    Not in the list? Add it by hand. Server type: ACE

    gs1.buadren.com:9000

  4. 4 Say hello

    Once you're through the portal, drop into Discord and let us know you made it — it's a small community, and we like knowing who's around.

    Join the Discord

Common questions

The launcher says the server is down. What now?

Check the live server status, then ask in Discord. If the status page shows the server up, the problem is probably on your side, and someone there can help you find it.

How many characters can I run at once?

Up to 5 concurrent clients per account.

Is there a test server?

Yes. It isn't in the public server list, it isn't persistent, and it gets wiped as needed to, well, test. If you want to help try out changes before they ship, ask in Discord for the current address.
