Getting started

Getting into Dereth

Five steps between here and standing on the shore. Most of it is one-time setup — after that, it's just launching Thwarg and picking Buadren from the list.

1

Get your game files

Buadren runs on ACE, so you'll need a working copy of the original Asheron's Call: Throne of Destiny client files before anything else will connect.

ACE's how-to-play guide →
2

Install Thwarg Launcher

Thwarg Launcher is what actually connects your client to emulated AC servers, Buadren included. Grab the installer from the official site.

thwargle.com →
3

Find Buadren in the server list

Open Thwarg Launcher, go to Browse Servers, and look near the bottom of the list for Buadren. Selecting it connects you to our live server.

Server type: ACE · Live address: gs1.buadren.com:9000
4

Optional: add the test server

Our test server isn't in the public Browse Servers list, so if you want to help try out changes before they ship, you'll need to add it by hand.

Test address: gs2.buadren.com:9000 — added manually. It is not persistent and gets wiped as needed to, well, test.
5

Say hello

Once you're through the portal, drop into Discord and let us know you made it — it's a small community, and we like knowing who's around.
